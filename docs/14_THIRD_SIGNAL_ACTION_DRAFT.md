# 14. Third Signal — 반복 캡처를 다음 행동으로

상태: 로컬 정책 엔진·Today 제안·초안 상세·이력 저장·테스트 구현  
정책 버전: `third-signal-v1`  
작성일: 2026-08-22

## 한 줄 결정

Echo는 사용자를 MBTI나 성격으로 추측하지 않는다. 사용자가 승인한 유사 캡처가 세 장 모이는 **관찰 가능한 행동**을 신호로 보고, 내용에 맞는 다음 행동 초안 하나를 제안한다.

사용자에게는 기능명을 노출하지 않고 `이어 볼까요?`라고 말한다.

## 왜 세 장인가

- 한 장은 임시 기억일 수 있다.
- 두 장은 우연한 중복일 수 있다.
- 세 장은 같은 대상·주제를 다시 찾은 반복 행동으로 해석할 최소 신호다.

세 장은 브랜드 순간이지 충분조건은 아니다. 묶음 승인, 일관된 의도, 다른 단서, 시간 범위, 민감도 검사를 모두 통과해야 한다. 네 번째 캡처가 생겨도 새 제안을 만들지 않고 최초 세 장의 초안을 유지한다.

## 내용별 결과

| 승인 의도 | 그룹 유형 | 결과 | 기본 시간 범위 |
|---|---|---|---:|
| 사고 싶음 | 같은 대상 | 결정 카드 | 45일 |
| 참고 | 같은 대상·주제 | 레퍼런스 보드 | 90일 |
| 읽기 | 같은 주제 | 읽기 브리프 | 30일 |
| 공유 | 같은 주제 | 공유 초안 | 14일 |

`간직`은 후속 행동을 강요하지 않는다. 일반 보관과 Useful Recall 흐름을 사용한다.

## 자격 조건

모든 조건을 만족해야 한다.

1. 리뷰에서 승인된 그룹이다.
2. 모든 항목이 `saved` 상태이고 분석이 완료됐다.
3. 세 항목의 최종 의도가 하나로 같다.
4. 그룹 confidence가 0.72 이상이다.
5. 제목·키워드·엔티티를 조합한 단서가 최소 두 종류다.
6. 의도별 시간 범위 안에서 촬영됐다.
7. 중복 그룹, 검토 필요 분석, 삭제·완료 항목, 대체된 그룹이 아니다.
8. 항목 또는 분석 결과에 민감 표시가 없다.

민감도와 lifecycle 검사는 제목, 키워드, 엔티티를 읽기 전에 short-circuit한다.

## 화면과 행동

Today 첫 슬롯에서만 하나를 보여준다.

1. `이어 볼까요?`
2. 구체적인 제목과 한 줄 이유
3. 실제 캡처 세 장을 하나로 묶은 triptych
4. 내용에 맞는 primary action 하나
5. `그대로 보관`

primary action을 누르면 로컬 초안을 연다. 공유, 삭제, 업로드, 구매, 외부 전송은 자동으로 실행하지 않는다. `그대로 보관` 또는 초안 열기 반응은 `ActionDraftInteraction`으로 기기에만 저장해 같은 제안을 반복하지 않는다.

## 저장 경계

`ThirdSignalSuggestion`에는 다음만 저장·전달한다.

- 정책 버전과 suggestion ID
- 그룹·항목 ID
- 결과 유형과 승인 의도
- 화면에 필요한 안전한 subject
- trigger item과 생성 시각

OCR 원문, 이미지 픽셀, 임베딩, hidden reasoning, confidence 설명은 interaction history에 넣지 않는다.

## 레퍼런스에서 취한 것과 버린 것

- ShotBox의 OCR 검색·스마트 컬렉션·원탭 액션은 캡처가 행동으로 이어져야 한다는 근거로 참고한다.
- Readwise의 daily review는 저장된 정보가 다시 등장해야 효용이 생긴다는 근거로 참고한다.
- Pinterest의 board/collage는 여러 시각 자료를 하나의 결과물로 만드는 모델로 참고한다.
- 검색함, 무한 피드, 자동 공개, 반복 리마인더를 그대로 복제하지 않는다.

Echo의 차이는 **정리된 보관함**이 아니라 **반복된 캡처를 사용자가 확인할 하나의 다음 행동 초안으로 바꾸는 것**이다.

## 성공 기준

- Third Signal Qualified Rate: 승인 그룹 중 제안 자격을 충족한 비율
- Draft Open Rate: 제안에서 초안을 연 비율
- Draft Completion Rate: 초안을 실제 보관·공유·읽기·결정 완료로 이어간 비율
- Dismiss Rate: `그대로 보관` 비율
- False Bundle Rate: 초안 진입 후 묶음을 수정하거나 제외한 비율

이미지, OCR 원문, 엔티티 값은 analytics payload에 포함하지 않는다.
