# 2026 App Store Review

확인일: 2026-08-21 · 대한민국 App Store

## 카테고리 판단

대한민국 `비즈니스` 무료 차트 상위권은 고용, 세금·행정, 구인, 중고차, 팩스 등 명확한 업무 도구가 중심이다. 스크린샷 정리 직접 참고 앱은 서로 다른 카테고리를 쓰지만 `생산성`과 `유틸리티`가 더 자주 관찰됐다.

- [대한민국 비즈니스 앱 차트](https://apps.apple.com/kr/iphone/charts/6000?l=en-GB)
- [Captr — 유틸리티](https://apps.apple.com/kr/app/captr-screenshot-organizer/id6738889624)
- [ShotBox — 생산성](https://apps.apple.com/kr/app/%EC%8A%A4%ED%81%AC%EB%A6%B0%EC%83%B7-%EC%A0%95%EB%A6%AC-shotbox/id6778151814)
- [CaptainShot — 라이프스타일](https://apps.apple.com/kr/app/captainshot-%EC%8A%A4%ED%81%AC%EB%A6%B0%EC%83%B7-ai/id6745024150)

현재 권고는 `생산성`을 1차 후보, `유틸리티`를 2차 후보로 두고 스토어 출시 직전에 차트와 키워드를 다시 검증하는 것이다.

## Phase 3 재확인

2026-08-21에 Apple의 현재 상품 페이지를 다시 확인했다. Captr는 유틸리티에서 자동 정리·Today 피드·행동 제안을, ShotBox는 생산성에서 기기 내 OCR·스마트 카테고리·주간 리뷰를, CaptainShot은 라이프스타일에서 로컬 분석·빠른 검토를 전면에 둔다. 따라서 Catch의 방어 가능한 차별점은 기능 이름이 아니라 `한 장씩 열지 않고, 저장한 이유별 묶음을 하루 한 번 승인하고, 바로 다시 찾는 완결된 행동`이다.

## 차별화 방향

경쟁 앱은 이미 자동 분류, 로컬 OCR, 데일리 피드, 원탭 액션, 컬렉션, 주간 리뷰를 설명한다. Catch Capture는 기능 목록보다 다음 한 문장으로 시작한다.

> 하루 한 번, 캡처한 이유별 묶음을 60초 안에 승인한다.

Phase 2 이후에는 `권한 허용률 → 첫 묶음 승인률 → 의도 수정률 → 60초 내 리뷰 완료율 → 7일 내 유용한 재발견`을 제품 가설의 측정 순서로 둔다.

## 출시 전 재검증 항목

- 실제 기기에서 PhotoKit 전체·제한·거부와 수동 선택 흐름
- 앱 생명주기와 사진 변경 감지 제약 아래의 자동 수집 약속
- Expo와 SwiftUI 중 스토어 주 구현 경로
- 민감 항목 가림, 공유 제외, 원본 삭제 분리의 실제 동작
