# 03. Information Architecture & User Flows

## 하단 내비게이션

1. `Library` — 보관함
2. `Today` — 오늘의 정리. 앱은 이 화면으로 시작한다.
3. `Search` — 찾기

하단에서는 세 목적지를 글자 없이 아이콘으로 보여준다. 왼쪽은 2×2 보관함 그리드,
가운데는 캡처 묶음과 체크를 결합한 정리 아이콘, 오른쪽은 검색 아이콘이다. 화면에
라벨을 숨겨도 접근성 이름 `보관함`, `오늘의 스크린샷 정리`, `찾기`는 유지한다.
가운데 아이콘은 Today 목적지이며 실제 리뷰 시작·재개는 Today의 상태가 설명된 CTA가
담당한다.

설정은 Today 또는 Library 상단의 프로필/설정 버튼으로 진입한다.

## 분류 체계

### Primary intent

| ID | 한국어 | 의미 |
|---|---|---|
| `reference` | 참고 | 업무, 프로젝트, 디자인, 마케팅, 학습 자료 |
| `want` | 사고 싶음 | 상품, 식당, 여행지, 예약 후보, 구매/방문 의향 |
| `share` | 공유 | 다른 사람에게 보내고 싶은 콘텐츠 |
| `read` | 읽기 | 기사, 긴 글, 정보성 콘텐츠 |
| `keep` | 간직 | 감정, 문장, 장면, 취향, 추억 |

## 핵심 사용자 흐름

### Flow 1. 첫 사용

1. 가치 제안
2. 개인정보 설명
3. 사진 접근 권한
4. 최근 스크린샷 가져오기 범위 선택
5. 정리 시간 선택
6. 초기 분석
7. 실제 캡처로 만든 첫 결과 확인
8. 첫 묶음 리뷰 또는 Today 진입

### Flow 2. 하루 정리

1. Today에서 새 캡처 수 확인
2. `오늘 정리 시작`
3. 첫 묶음 미리보기
4. `모두 참고로 보관` 또는 `하나씩 확인`
5. 필요 시 일부 항목 분류 수정
6. 다음 묶음
7. 제거 후보 확인
8. 정리 완료

### Flow 3. 검색과 재발견

1. Search 진입
2. 자연어 또는 키워드 입력
3. 관련도 높은 큰 카드 + 나머지 그리드
4. 상세 진입
5. 공유, 컬렉션 추가, 원본 보기, 완료 처리

### Flow 4. 사고 싶은 것 관리

1. `want` 필터
2. 브랜드/상품/장소별 보기
3. 비교용 컬렉션 추가
4. 구매 또는 방문 완료 처리
5. 완료 항목은 기본 그리드에서 숨기거나 필터로 보기

### Flow 5. 민감 항목 공유

1. 상세에서 공유 선택
2. 민감 콘텐츠 경고
3. 자동 블러 후보 확인
4. 포함할 영역/항목 선택
5. 공유 카드 미리보기
6. 시스템 공유 시트 호출

### Flow 6. 반복 캡처를 다음 행동으로

1. Review에서 관련 캡처 그룹을 승인한다.
2. 승인된 비민감 캡처 세 장이 `third-signal-v1` 자격을 통과한다.
3. Today 첫 슬롯에 `이어 볼까요?`와 실제 캡처 triptych가 나타난다.
4. 사용자는 내용별 초안 하나를 열거나 `그대로 보관`한다.
5. 초안에서 각 원본과 그룹 요약·묶은 근거를 확인한다.
6. 외부 공유·삭제·업로드는 별도 명시적 확인 뒤에만 실행한다.

## 빈 상태

### Today — 새 항목 없음

- 제목: `오늘은 새로 주운 장면이 없어요`
- 설명: `스크린샷이 생기면 여기에 조용히 모아둘게요.`
- 보조 액션: `최근 보관함 둘러보기`

### Library — 저장 없음

- 제목: `아직 보관한 스크린샷이 없어요`
- 설명: `첫 정리를 끝내면 이곳에서 다시 찾을 수 있어요.`

### Search — 결과 없음

- 제목: `비슷한 장면을 찾지 못했어요`
- 설명: `출처, 시기, 색상, 상품명처럼 기억나는 단서를 더해보세요.`
