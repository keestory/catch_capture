# Echo Product Principles v1.0

## Product Vision

Echo is a personal interest memory OS.

It transforms forgotten screenshots into meaningful discoveries.

## North Star

Users regularly rediscover something they saved and take action.

Examples:

- Buy something
- Visit somewhere
- Learn something
- Share something
- Create something

## Core Loop

Discover → Capture → Understand → Rediscover → Act

## Product Decisions

Every feature must improve at least one:

1. Remember
2. Understand
3. Rediscover

If not, do not build.

## Viral Loop

Weekly Interest Report.

Example:

"My week with Echo"

- Running 31%
- Design 25%
- Travel 18%

Users can share their personal discovery patterns.

## MVP Priority

Phase 1:

- Screenshot ingestion
- AI grouping
- Daily Brief
- Keep/Delete cleanup

Phase 2:

- Interest Map
- Weekly Report
- Personalized recommendations

## Metrics

North Star Metric:

Weekly Rediscovered Memories

Supporting:

- Daily Brief open rate
- Keep rate
- Action conversion
- Weekly active users
