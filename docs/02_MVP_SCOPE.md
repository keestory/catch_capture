# 02. MVP Scope

## MVP 목표

사용자가 새 스크린샷을 가져와 의도별 묶음을 확인하고, 보관함에서 다시 찾는 핵심 루프를 검증한다.

## 반드시 포함

### A. 온보딩

- 앱 가치 제안 2~3장
- 스크린샷 접근 권한 요청
- 일반 사진은 기본적으로 표시하지 않는다는 설명
- 분석 방식과 개인정보 처리 설명
- 기본 정리 시간 선택 또는 건너뛰기

### B. 가져오기

- 새 스크린샷 감지 또는 사용자가 수동으로 선택
- 수집 대기, 분석 중, 완료, 실패 상태
- 중복 후보 탐지
- 장문의 세로 스크린샷 표시

### C. 오늘 화면

- 오늘의 새 캡처 개수
- AI가 만든 묶음 수
- 의도별 개수 요약
- 예상 정리 시간
- 정리 시작 CTA
- 새 캡처 없음 상태

### D. 하루 정리

- 묶음 단위 제안
- 전체 승인
- 하나씩 확인
- 분류 변경
- 중복 묶기/분리
- 삭제/보관
- 실행 취소
- 정리 완료 화면

### E. 보관함

- 2열 메이슨리 또는 균형 그리드
- 날짜 구분
- 의도 필터
- 출처/유형 메타데이터
- 상세 화면 진입

### F. 상세 화면

- 원본 스크린샷
- 제목, 요약, 출처, 캡처 시각
- 의도 수정
- 관련 항목
- 컬렉션 추가
- 공유
- 앱에서 제거
- 기기 사진에서도 삭제

### G. 검색

초기에는 완전한 생성형 검색보다 로컬 인덱스 검색을 우선한다.

- OCR 텍스트
- AI 생성 제목
- 요약
- 출처
- 의도
- 콘텐츠 유형
- 날짜

검색 예시:

- 검정 러닝화
- 지난달 경쟁사 이벤트
- 공유하려던 기사
- 인스타에서 본 베를린 식당

### H. 개인정보

- 민감 콘텐츠 플래그
- 공유 기본 제외
- 앱 잠금 옵션 구조
- 삭제 분리
- 분석 저장 위치 설명

## MVP에서 선택

- 알림 예약
- 컬렉션 생성
- 유사 항목 추천
- 로컬 임베딩 기반 검색
- 간단한 공유 카드

## MVP 이후

- 가격 추적
- 원본 링크 복구
- 협업 컬렉션
- 웹 클리퍼
- 브라우저 확장
- 팀용 레퍼런스 보드
- 주간 취향 리포트
- 외부 메신저로 공유 예약
- 자동 리마인더

## 제품 제약

- 하루 리뷰가 60초를 넘지 않도록 설계한다.
- 기본 경로에서 한 장씩 검토하지 않는다.
- AI 분류가 틀려도 수정 비용이 낮아야 한다.
- 모든 자동화에는 사용자 제어권이 있어야 한다.
- 민감 콘텐츠는 바이럴 기능보다 우선한다.
