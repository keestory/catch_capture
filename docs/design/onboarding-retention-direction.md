# Onboarding to Retention Direction

## Selected direction

The first-value screen leads with the user's real screenshots and one visible result:

1. `8장을 3묶음으로 준비했어요.`
2. A small set of current screenshots linked to one relevant past screenshot.
3. Two plain evidence statements: automatic grouping and rediscovery.
4. One primary action to review the first group.

The interactive design-lab route continues through group review, completion, and next-day recall so the product promise is demonstrated before a notification request becomes the main retention mechanism.

## Research findings

- Current iOS guidance favors direct hierarchy, familiar controls, and visual elements that earn their place. Decorative icon containers are not necessary when the copy is already clear.
- SF Symbols guidance supports symbols as familiar semantic aids, but not as repeated ornament around explanatory marketing rows.
- Image-first products such as Pinterest and mymind keep the saved content dominant and reduce manual-organization language.

## Rejected pattern

The previous lower section used a circular outlined icon, a benefit sentence, and a divider for every feature. That read as a generic landing-page feature list and competed with the screenshot relationship above it.

The original value-onboarding hero also placed an English kicker and repeated Korean benefit copy over a dark branded illustration. It read as a marketing banner, duplicated the page heading, and hid the product evidence. The production value screen now uses two real example captures, plain recent/past labels, and one measured product sentence on the neutral canvas.

## Production rule

Use `OutcomeEvidence` instead:

- `자동 정리 · 8장 → 3묶음`
- `한 장씩 분류하지 않아도 돼요.`
- `재발견 · 지난 장면 2개`
- `잊고 있던 장면을 다시 볼 수 있어요.`

No icon circle, card, pill, or internal divider is added to this block.
