# Mock Data Requirements

최소 20개 항목을 만들 때 아래 구성을 만족한다.

## Reference — 5

- 경쟁사 쇼핑 앱 상품 상세 UI
- 타사 이벤트 랜딩 페이지
- 광고 크리에이티브
- 가격 정책 표
- 소셜 콘텐츠 포맷

## Want — 4

- 러닝화 상품
- 가방
- 베를린 식당
- 전시 티켓

## Share — 4

- 재미있는 밈
- 공감 문장
- 친구에게 보낼 뉴스
- 영상 장면

## Read — 3

- 긴 뉴스 기사
- AI 리포트
- 인터뷰 글

## Keep — 4

- 감정적인 문장
- 여행 풍경
- 인테리어 장면
- 스타일 레퍼런스

## Edge cases

- 동일 상품 3장
- 연속 스크롤 캡처 2장
- 세로 길이 5,000px 이상인 긴 캡처
- 메신저 대화 포함 민감 항목
- 주소와 주문번호 포함 항목
- OCR 실패
- 출처 미상
- AI 분류 confidence 낮음
- 삭제 취소 시나리오
